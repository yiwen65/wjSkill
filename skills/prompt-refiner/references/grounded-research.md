# Grounded research prompts

Read this file only when the target prompt requires retrieval, factual analysis,
citations, or evidence.

Specify only the evidence controls that affect the task:

- which claims require support;
- acceptable source types and freshness;
- where citations should appear;
- how to label inference, uncertainty, and source conflicts;
- what to do when evidence is unavailable.

Prefer current primary sources for time-sensitive or authoritative facts.
Allow reputable secondary sources when they provide necessary independent
context, comparison, or corroboration. Do not require a citation for every
sentence when claim-level support for material facts is sufficient.

Absence of evidence is not automatically evidence of absence. Narrow the claim,
mark the information unavailable, or state the evidence gap rather than guessing.

Resolve breadth versus brevity by prioritizing decision-relevant dimensions,
not by adding a large universal report template. Add a bounded stopping rule
only when retrieval could otherwise become open-ended, such as stopping after
required dimensions are supported or marked unavailable and another focused
search would not materially change the conclusion.

For creative work that uses supplied facts, keep sourced facts distinct from new
language. Do not invent names, dates, metrics, capabilities, customers, prices,
or outcomes to strengthen the result.
