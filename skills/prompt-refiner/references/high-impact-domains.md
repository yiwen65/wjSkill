# High-impact domains

Read this file only for legal, medical, financial, employment, safety, security,
or compliance prompts.

Preserve material jurisdiction, dates, source requirements, uncertainty,
professional boundaries, escalation rules, and human approval requirements.
Ask when a missing detail could materially change the risk or result.

Do not turn general caution into repetitive boilerplate. Add a disclaimer only
when it changes how the output should be interpreted or used.

Do not replace enforceable controls with prompt wording. Access restrictions,
approval gates, transaction limits, confidentiality boundaries, and destructive
action controls should remain explicit and, when the target system supports it,
enforced by architecture rather than model judgment alone.
